
## Dataset Overview

This project uses the airline customer reviews dataset supplied by the module coordinator for the ITAG7105 – Data Mining coursework at Queen’s University Belfast.

The dataset contains structured passenger ratings and unstructured written reviews. It supports descriptive analytics, predictive modelling, and text analytics to investigate customer recommendation behaviour.

## Dataset Source

According to the coursework brief, the dataset is based on an existing dataset downloaded from Kaggle for educational purposes.

The module coordinator supplied the specific dataset version required for the assessment.

**Dataset file:** `MGT0000_ITAG7105_new_dataset_final.xlsx`

## Important Usage Information

- The dataset was provided for educational use as part of the ITAG7105 coursework.
- The module teaching team does not own the original dataset.
- The module teaching team does not guarantee the accuracy of the dataset.
- The original dataset's author, source URL, and redistribution licence have not been identified in the available coursework brief.

Users should verify the original Kaggle dataset's licence and terms before redistributing, reusing, or using the dataset commercially.

## Intended Use

The dataset was used for:

- Descriptive analysis of airline service ratings.
- Predictive modelling of customer recommendation behaviour.
- Text preprocessing and sentiment analysis.
- TF-IDF feature extraction.
- Combined numerical and textual feature modelling.
